# Current research status

## Demonstrated

- Deterministic synthetic 3D routing and comparative measurement across 292
  fixed requests, with explicit completeness/conflict trade-offs.
- Bounded real-IFC reading, source-mesh provenance, endpoint evidence,
  unit/placement checks, and a viewer for DigitalHub Phase 11B artifacts.
- One saved real-IFC A* search path (DH11B-V1), with a recorded
  `CLEARANCE_VIOLATION`; four other Phase 11B requests are `SEARCH_NO_PATH`.

## Not demonstrated

- A physically acceptable DigitalHub Phase 11B route: **0/5**.
- General real-IFC routing, actual multi-system real-IFC coordination,
  connector/fitting generation, validated penetrations, or IFC write-back.
- Building-code, fabrication, maintenance, support, or jurisdictional approval.

## Publication gate

Any publication must distinguish controlled synthetic conflict metrics from
real-IFC physical validation. It must report the invalid Phase 11A proxy route,
the endpoint correction, all Phase 11B no-path results, and V1's clearance
failure. The next claim requiring evidence is a physically acceptable,
connector-valid real-IFC route under a declared clearance policy.
